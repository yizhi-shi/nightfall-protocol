# 夜幕协议 — 声音、天气与叙事设计（v1.2）

> 目标：解决“只有雨声、所有场景都是雨夜、关卡情绪单一”的问题。

## 1. 调研结论

- **自适应音乐采用垂直分层**：同一 BPM 下所有层同步播放，按战斗强度淡入/淡出环境铺底、脉冲、打击和旋律层；这比切歌更适合 FPS 的连续战斗。[Adaptive Music 参考](https://github.com/absolutelyskilled/absolutelyskilled/blob/57ca1866b8b4ea31a23a0971d70814826c2db6f6/skills/game-audio/references/adaptive-music.md)
- **灯光是叙事和引导工具**：冷色/低照度制造距离与危险，暖色局部光把注意力引向目标；明暗对比比整体提高亮度更有效。[Level Design 资源论文](https://upcommons.upc.edu/bitstream/handle/2117/173957/Thesis-Level%20Design_Resources%20and%20techniques%20to%20guide%20the%20player.pdf?sequence=1&isAllowed=y)
- **环境叙事靠空间、痕迹、标识、光和声音**：一盏还能工作的灯、半开的卷帘门、被拖拽过的椅子，比旁白更可信。[Environmental Storytelling](https://skrib.com/blog/environmental-storytelling-writing-narrative-into-level-design)
- **叙事信息应该分层**：主线由无线电推进，次级信息藏在场景和物件里，玩家可以忽略但不影响通关。[Gone Home / Fullbright 访谈](https://www.engadget.com/2014-09-26-stories-we-tell-in-quiet-houses-and-alien-invasions.html)

## 2. 声音需求

### 每关独立配乐

| 关卡 | 情绪 | 音乐特征 |
| --- | --- | --- |
| 01 泵站 | 压抑、坚持 | 低音锯波铺底 + 缓慢工业脉冲 + 雨 |
| 02 货柜场 | 黄昏、空旷、警觉 | 多利亚调式三角波 + 稀疏拨弦 + 风声，无雨 |
| 03 变电站 | 高压、神经质 | 弗里吉亚调式 + 快速琶音 + 电嗡鸣 |
| 04 铸造厂 | 沉重、灼热 | 低音铜管式铺底 + 铁砧打击 + 炉膛低频 |
| 05 码头 | 潮湿、疲惫 | 小调铺底 + 缓慢脉冲 + 风/水/雨 |
| 06 中继塔 | 冷峻、终局 | 正弦合唱铺底 + 服务器高频 + 稀疏琶音 |

### 自适应层

- **Pad**：始终存在，提供调性。
- **Bass**：探索时低音量，战斗时加重。
- **Arp**：探索时稀疏，战斗时密度/音量上升。
- **Perc**：战斗时进入，使用程序化噪声与金属脉冲。
- **Stinger**：完成节点、开门、胜利、失败各有一条短促提示。
- 所有层共享同一 BPM，切换不重启小节。

### 场景环境声

- 雨声根据关卡天气开启/关闭；干区室内降低雨声。
- 风、工业低频、电嗡鸣、炉膛轰鸣、服务器低频分别由 WebAudio 合成。
- 进入室内时降低雨声并加入低频房间底噪。
- 关闭环境声不能影响枪声、脚步和音乐。

## 3. 天气 / 时间 / 亮度

| 关卡 | 天气 | 时间 | 曝光 | 关键光 |
| --- | --- | --- | --- | --- |
| 01 泵站 | 暴雨 + 闪电 | 深夜 | 1.36 | 冷月光 + 暖工作灯 |
| 02 货柜场 | 雨停、湿地面 | 黄昏 | 1.30 | 低角度暖阳 + 钠灯 |
| 03 变电站 | 雷暴 | 深夜 | 1.30 | 冷白开关场 + 青色电弧 |
| 04 铸造厂 | 室内 | — | 1.12 | 熔炉橙光 + 顶部工灯 |
| 05 码头 | 小雨 | 夜 | 1.20 | 绿色航灯 + 仓库冷光 |
| 06 中继塔 | 室内 | 黎明前 | 1.15 | 冷白大厅 + 红色应急灯 |

原则：

- 不同关卡的曝光、雾色、天空色、主光和点光色温必须不同。
- 亮度不是整体拉高，而是“暗部可读 + 目标区域有对比”。
- 室内要保证门框、地面和目标可见；避免全黑或纯白过曝。
- 室外黄昏/白天场景不能继续使用暴雨夜天空。

## 4. 叙事需求

- 每关有独立的行动目标、环境故事和结尾文案。
- 主线通过“指挥部 / 灯塔”的无线电推进；每关 3 条故事节拍。
- 故事文本必须中文、短句、可在战斗中快速读完。
- 结局文案随关卡变化，最后一关收束整个战役。
- 环境叙事补充：卷帘门、货架、控制台、警示牌、服务器灯、遗留工具。
- 不强制玩家阅读文本；所有关键目标仍有 HUD 指引。

## 5. 验收

1. 六关音乐主题不同，进入战斗后至少两层音量变化。
2. 02 关无雨声/雨线，能听到风声和黄昏音乐；01/03/05 有雨声。
3. 04/06 室内无雨声，能听到炉膛/服务器环境声。
4. 无线电故事节拍按时间出现，标题为“指挥部”或“灯塔”。
5. 六关曝光/天空/雾色不同；02 黄昏、01/03 夜雨、04/06 室内清晰可读。
6. 无 WebAudio 异常、无控制台错误。
