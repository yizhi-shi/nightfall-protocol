# 夜幕协议 — 关卡丰富度调研与 v1.1 需求

> 状态：v1.1 设计基线  
> 目标：解决六关“同一张外场换皮”的同质化问题，增加室内空间、空间节奏、目标差异和可读性。

## 1. 调研结论

参考了以下公开资料与关卡案例：

- [关卡设计概念：边界主导 / 兴趣点主导](https://www.gameres.com/forum/t/886763#2)：走廊、门和短视线制造高压；开放空间和兴趣点制造探索与喘息。两种节奏需要交替，而不是整关只有一种。
- [Prospect / Refuge 空间理论（SMU 论文）](https://scholar.smu.edu/cgi/viewcontent.cgi?article=1004&context=guildhall_leveldesign_etds)：开阔的“远景空间”让玩家暴露、紧张；封闭的“庇护空间”提供掩护和恢复。紧张与安全必须有起伏。
- [废弃办公室室内关卡分析](https://www.zcool.com.cn/work/ZNzI3NzQ2NTY=.html)：7m×15m 的中型房间、非对称书架掩体、单一入口但多视线、中心决策点、暖室内/冷室外、动态火花与灰尘、弹孔叙事。
- [Environment Stories](https://www.gamedeveloper.com/design/level-design---environment-stories)：用破损、遗留物、标识和光线方向讲故事，而不是只放掩体。
- [The Level Design of Tacoma](https://80.lv/articles/the-level-design-of-tacoma)：室内空间的叙事密度来自可读的日常物件、区域划分和玩家可推断的动线。

归纳出的可执行原则：

1. **压缩 / 释放（compression / release）**：狭窄入口 → 中庭/大厅 → 侧室 → 开放外场，不能全程空旷，也不能全程走廊。
2. **远景 / 庇护（prospect / refuge）**：开放区域提供远视线和风险，室内房间、门框、货架和柱子提供短视线掩护。
3. **非对称掩体**：避免左右镜像的对称蹲点；用货架、控制台、 furnace、变压器形成不同高度的遮挡。
4. **可读的边界**：门框、地面材质、灯光色温、天花板高度和标识牌要能告诉玩家“这里是室内/室外/危险区”。
5. **视觉地标**：每关有一个独特的大体量地标（泵站立面、货柜墙、变压器阵列、熔炉、仓库卸货口、通信塔核心）。
6. **环境叙事**：撤离遗留物、工牌、警示牌、监控、破损、积水、弹孔和局部光源。
7. **反重复**：每关至少改变拓扑、目标道具、光照逻辑、室内比例中的两项；不能只换颜色和道具。
8. **性能预算**：室内用少量点光源 + 自发光面板 + 体积光锥；不引入实时反射或大量动态光。

## 2. 当前六关审计

| 关卡 | 当前空间 | 主要问题 |
| --- | --- | --- |
| 01 泵站 | 室外工业院 | 有完整主楼，但仍是唯一有真正“建筑体量”的关卡 |
| 02 货柜场 | 室外货柜迷宫 | 布局有变化，但缺少屋顶、房间、可进入建筑 |
| 03 变电站 | 室外变压器阵列 | 控制室只是实心盒子，无法进入；目标都在露天 |
| 04 铸造厂 | 室外 + 局部雨棚 | 熔炉可见，但没有真正车间室内感；雨穿屋顶 |
| 05 码头 | 室外码头 | 水面和吊机有辨识度，但缺少仓库内部和装卸空间 |
| 06 中继塔 | 室外塔基 | 中央塔只是实心方块，没有塔内大厅、机房和门禁 |

共性问题：

- 六关共用同一圈外墙、同一个北门、同一个南侧出生区和同一种三人称目标柱。
- 目标交互物都是同一种“继电器控制台”，只换屏幕文字。
- 室内只存在于泵站主楼，其余关卡没有可进入的室内空间。
- 雨是全局粒子，室内没有干区遮罩，无法自然做“室内外切换”。
- 关卡差异主要来自道具摆放和灯光颜色，空间拓扑差异不足。
- 敌人配置都是 8 人、同一套波次，缺少室内 CQB 和房间清理节奏。

## 3. v1.1 需求

### R1 室内空间（必须）

- 04 铸造厂：整关改为**室内铸造车间**，有完整屋顶、梁架、天窗/灯具、熔炉、吊梁、控制室。
- 05 码头：改为**码头仓库 + 卸货口**，大部分战斗在室内，东侧卸货口可看到雨中的运河、吊机和水面。
- 06 中继塔：改为**塔内大厅 + 三个机房**，中央塔核心、服务器房、控制室、北侧核心机房。
- 03 变电站：增加可进入的**主控室**，目标 C 位于室内，南北双门连接外场和北门。
- 02 货柜场：保留室外迷宫，增加覆盖式装卸雨棚（半室内干区），并强化集装箱堆叠与吊装地标。
- 01 泵站：保留现有室外+主楼，升级继电器为对应主题道具。

### R2 雨与室内外过渡（必须）

- 全室内关卡（04、06）：关闭雨线和地面溅水，增加室内灰尘、体积光、机械/服务器低鸣。
- 混合关卡（03 主控室、05 仓库、02 控制亭）：使用矩形干区遮罩，只隐藏屋顶覆盖范围内的雨，室外仍下雨。
- 室内地面、天花板、梁架、灯具必须可读，不能出现“室外雨直接穿过屋顶”的明显穿帮。

### R3 门与可进入房间（必须）

- 增加自动滑动门：玩家靠近时滑开，门碰撞体移除；门框、门板、状态灯可见。
- 03 主控室：南门、北门。
- 04 铸造厂控制室：东门。
- 05 仓库：南侧主入口卷帘门、西侧办公室门。
- 06 中继塔：西机房、东控制室、北核心机房的房门。
- 门必须参与碰撞；开门后不能留下隐形墙。

### R4 目标道具差异化（必须）

- 01 泵站：继电器控制台。
- 02 货柜场：导航信标（天线 + 信号环）。
- 03 变电站：断路器柜（柜体 + 拉杆 + 电弧条）。
- 04 铸造厂：炉心阀门（大转轮 + 管道）。
- 05 码头：码头控制终端（多屏 + 键盘）。
- 06 中继塔：服务器机柜（LED 阵列 + 机架）。
- 每关交互动词不同：覆盖 / 校准 / 闭合 / 关闭 / 接入 / 接入。

### R5 室内美术与道具（必须）

- 铸造厂：屋顶梁架、工业吊灯、天窗光柱、炉口光、蒸汽、吊梁、钢包、管线、控制室、阀门。
- 仓库：货架、托盘、叉车、卷帘门、装卸口、地面标线、吊灯、监控、办公室。
- 中继塔：服务器机柜、控制台、玻璃隔断、电缆桥架、红色应急灯、中央塔核心、接待台。
- 变电站主控室：配电柜、监控屏、桌面、椅子、窗格、警示标识。

### R6 关卡拓扑与节奏（必须）

- 04、05、06 需要“入口 → 主厅 → 侧室 → 目标 → 撤离”的明确节奏，不能一进门就是全图。
- 每关至少有一条主路线和一条侧路线；室内房间要形成短视线和近战决策点。
- 中央地标不能只是装饰：熔炉、货架/装卸口、塔核心要参与遮挡和空间分区。
- 敌人出生点和巡逻路线必须覆盖室内外，不得卡在墙里。

### R7 性能与可读性（必须）

- 室内点光源总数控制在 4–6 个；用自发光面板、光锥和环境光补足。
- 天花板不能压到玩家视线；门高≥3.0m，主厅净高≥6m。
- 门口、目标、撤离方向要有色彩或灯光引导。
- 低画质下也要保留室内轮廓、目标和门的状态。

### R8 测试与交付（必须）

- 六关全部加载/启动，3 个目标、8 名敌人、无控制台错误。
- 每个门可打开，开门后碰撞体移除；玩家可从门通过。
- 全室内关卡雨线/溅水不可见；混合关卡屋顶下无雨、屋外有雨。
- 室内目标可正常长按完成；完整流程至少在两关实测通关。
- 720p / 900p 开始界面不溢出；关卡选择、下一关、难度保持正常。
- 更新 PROMPT.md、README、截图和发布包；提交并推送。

## 4. 验收标准

1. `?level=4`、`?level=6` 的 `rain.mesh.visible === false`，室内灰尘可见。
2. `?level=5` 仓库内部截图无雨线，东侧卸货口外有雨/水面/吊机。
3. 03、04、05、06 的门在玩家靠近后打开，碰撞体从 `world.colliders` 移除。
4. 04 目标 C、05 目标 A/B/C、06 目标 A/B/C 均在室内可交互。
5. 六关截图能一眼区分室外泵站、货柜迷宫、变电站、铸造车间、仓库、塔内大厅。
6. 所有测试通过后再更新版本号、提示词、README，并 commit/push。


## 5. v1.1 实现状态

- 03 变电站：主控室已实现，南北双自动门，干区雨遮罩，目标 C 位于室内。
- 04 铸造厂：整关改为室内铸造车间，完整屋顶/梁架/吊灯/天窗光柱/熔炉/环形检修台/西侧控制室。
- 05 码头：改为码头保税仓库 + 东侧卸货口，仓库内部干区、卷帘门、办公室门、货架、叉车、办公室；卸货口外仍可见雨、水面和吊机。
- 06 中继塔：改为塔内大厅 + 西机房/东控制室/北核心机房，四道自动门，服务器机柜与应急红灯。
- 02 货柜场：增加覆盖式装卸雨棚和干区遮罩。
- 目标道具：继电器、信标、断路器、阀门、控制台、服务器六种类型。
- 雨：全室内关卡隐藏雨线/溅水并显示室内灰尘；混合关卡使用矩形干区遮罩。
- 音频：室内降低雨声、增加低频房间底噪；自动门有机械开合声。

## 6. v1.2 声音 / 天气 / 叙事追加需求

- 六关配乐必须有独立调式、BPM、音色和场景环境声；不能只有雨声。
- 采用垂直分层自适应音乐：Pad / Bass / Arp / Perc，战斗时增强 Arp/Perc/Bass。
- 完成节点、开门、胜利、失败各有 stinger。
- 02 货柜场改为“雨停后的黄昏”，关闭雨线和雨声，改用风声与暖色夕阳。
- 01/03/05 保留雨，但雨强、天空、主光和闪电策略不同；04/06 室内无雨。
- 每关独立曝光、天空色、雾色和主光色温；明确亮度计划。
- 每关加入 3 条“指挥部 / 灯塔”无线电故事节拍和独立胜利/失败文案。
- 验收见 `docs/AUDIO_NARRATIVE.md`。
